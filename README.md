A simple calculator application built with HTML, CSS, and vanilla JavaScript as part of Week 3 of my learning journey.
The goal of this project is to practice DOM manipulation, event handling, and basic application logic in JavaScript.

---

## 🚀 Live Demo
https://vlasmar.github.io/Calculator-App/

---

## 🧱 Features
- Display screen to show input and results
- Number buttons 0–9
- Operator buttons:
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- Equals (=) button to calculate results
- Clear (C) button to reset the calculator
- Handles user input dynamically via button clicks

## 🛠️ Technologies Used
- HTML – Structure
- CSS – Styling
- JavaScript (ES6) – Logic and interactivity
